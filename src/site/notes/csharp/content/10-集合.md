# 集合

#### 1. 集合概述

##### 1.1 集合 vs 数组

| 对比 | 数组 | 集合 |
|------|------|------|
| 长度 | 固定，`Length` | 可变，`Count` |
| 元素类型 | 任意 | 泛型 `List<T>` 里是 `T`，可放值类型且不装箱 |
| 功能 | 只有索引与 `Array` 静态方法 | 增删改查、查找、排序、集合运算 |
| 适用 | 长度已知、追求极致性能 | 绝大多数业务场景 |

##### 1.2 接口层次

`IEnumerable<T>` → `ICollection<T>` → `IList<T>` / `IDictionary<K,V>` / `ISet<T>`。能力逐层增加，编程时 `面向接口`：

```csharp
List<string> list = new() { "a", "b" };

IEnumerable<string> enumerable = list;    // 只能遍历
ICollection<string> collection = list;    // + Add / Remove / Count
IList<string> ilist = list;               // + 索引器

IEnumerable<string> query = list.Where(x => x != "a");   // 惰性，不复制
foreach (string item in query)
{
    Console.WriteLine(item);              // b
}
Console.WriteLine(collection.Count);      // 2
Console.WriteLine(ilist[1]);              // b
```

> **注意**：方法参数尽量声明成 `IEnumerable<T>`（只读遍历）或 `IReadOnlyList<T>`（要下标），把"会不会被修改"写进签名，调用方更放心。

#### 2. List\<T\>

底层是 `可扩容数组`：容量不够时翻倍扩容并复制，所以 `按索引访问 O(1)`、`中间插入/删除 O(n)`。

```csharp
var nums = new List<int> { 3, 1, 4 };

nums.Add(1);                     // 尾部追加，均摊 O(1)
nums.AddRange(new[] { 5, 9 });    // 批量追加
nums.Insert(0, 7);                // 指定位置插入，O(n)
nums.Remove(1);                   // 删除首个匹配元素
nums.RemoveAt(0);                 // 按下标删除
Console.WriteLine(nums.Contains(4));   // True
Console.WriteLine(nums.IndexOf(4));    // 2
Console.WriteLine(nums.Count);         // 4

Console.WriteLine(string.Join(",", nums.ToArray()));   // 1,4,5,9
```

- 已知元素个数时用 `new List<T>(capacity)` 预分配，避免多次扩容
- `RemoveAll(predicate)` 一次删掉所有满足条件的元素，比循环 `Remove` 快
- `Sort()` 原地排序，`OrderBy()` 返回新的 `IEnumerable<T>`（LINQ，不修改原集合）

#### 3. Dictionary\<K,V\>

哈希表实现：`按 key 增删查平均 O(1)`，`key 唯一`，遍历顺序不保证（.NET Core 3.0+ 通常按插入顺序，但不要依赖）。

```csharp
var ages = new Dictionary<string, int>
{
    ["Tom"] = 18,                 // 索引器初始化：键不存在即新增
    ["Jerry"] = 20,
};

ages["Lucy"] = 22;                // 新增
ages["Tom"] = 19;                 // 覆盖
Console.WriteLine(ages["Tom"]);   // 19
Console.WriteLine(ages.ContainsKey("Jerry"));     // True
Console.WriteLine(ages.TryGetValue("Nobody", out int age));   // False，不抛异常

foreach (KeyValuePair<string, int> kv in ages)
{
    Console.WriteLine($"{kv.Key}={kv.Value}");
}
// ages["Nobody"];    // 抛 KeyNotFoundException
```

- 取值优先 `TryGetValue`；`GetValueOrDefault` 在缺失时返回 `default`，不会抛异常
- 用不存在的 key 索引会抛 `KeyNotFoundException`，这是最常见的线上异常之一
- 自定义类型做 key 必须正确实现 `Equals` / `GetHashCode`，否则查不到；`record` 天然满足

#### 4. HashSet\<T\>

只存不重复的元素，靠 `GetHashCode` + `Equals` 判重，`Add` / `Contains` / `Remove` 平均 `O(1)`。

```csharp
var set = new HashSet<int> { 1, 2, 2, 3 };

Console.WriteLine(set.Count);        // 3，自动去重
Console.WriteLine(set.Add(3));       // False，已存在
Console.WriteLine(set.Add(4));       // True
Console.WriteLine(set.Contains(2));  // True

set.IntersectWith(new[] { 3, 4, 5 });   // 交集 → { 3 }
set.UnionWith(new[] { 8 });             // 并集 → { 3, 8 }
set.ExceptWith(new[] { 8 });            // 差集 → { 3 }
Console.WriteLine(string.Join(",", set));   // 3
```

去重首选 `HashSet<T>`：`list.Distinct().ToList()` 内部也是先建一个 `Set`，但多一次遍历和分配。

#### 5. Queue\<T\> 与 Stack\<T\>

| 类型 | 规则 | 入 | 出 | 查看 |
|------|------|----|----|------|
| `Queue<T>` | 先进先出 FIFO | `Enqueue` | `Dequeue` | `Peek` |
| `Stack<T>` | 后进先出 LIFO | `Push` | `Pop` | `Peek` |

```csharp
var queue = new Queue<string>();
queue.Enqueue("a");
queue.Enqueue("b");
Console.WriteLine(queue.Peek());       // a，不出队
Console.WriteLine(queue.Dequeue());    // a，出队 FIFO
Console.WriteLine(queue.Count);        // 1

var stack = new Stack<int>();
stack.Push(1);
stack.Push(2);
Console.WriteLine(stack.Peek());       // 2
Console.WriteLine(stack.Pop());        // 2，LIFO
Console.WriteLine(stack.TryPop(out int v));   // False，空了不抛异常
```

队列常用于任务排队、广度优先搜索；栈用于撤销、括号匹配、深度优先搜索。并发场景用 `ConcurrentQueue<T>` / `ConcurrentStack<T>`。

#### 6. LinkedList\<T\>

双向链表：`按节点插入/删除 O(1)`，但 `按索引查找 O(n)`，且节点分散、缓存不友好。

```csharp
var linked = new LinkedList<string>();
var first = linked.AddFirst("b");       // 头插，返回节点
linked.AddLast("c");                    // 尾插
linked.AddAfter(first, "b2");           // 节点后插入，O(1)
linked.AddBefore(first, "a");           // 节点前插入

Console.WriteLine(linked.First!.Value); // a
Console.WriteLine(linked.Last!.Value);  // c

LinkedListNode<string>? node = linked.Find("b2");
linked.Remove(node!);                   // 按节点删除，O(1)
Console.WriteLine(string.Join(",", linked));   // a,b,c
```

绝大多数场景用 `List<T>` 就够；只有"边遍历边频繁在中间插入/删除、且已持有节点"时才考虑 `LinkedList<T>`。

#### 7. 泛型与类型约束

泛型让同一个算法适配多种类型，且 `值类型不装箱`。约束用 `where T : ...` 声明：

| 约束 | 含义 |
|------|------|
| `where T : class` | 必须是引用类型 |
| `where T : struct` | 必须是值类型（不含可空） |
| `where T : new()` | 必须有公共无参构造 |
| `where T : BaseClass` | 必须继承自某基类 |
| `where T : IComparable<T>` | 必须实现某接口 |

```csharp
public static T Max<T>(T a, T b) where T : IComparable<T>
    => a.CompareTo(b) >= 0 ? a : b;

public class Repository<T> where T : class, new()
{
    private readonly List<T> _items = new();

    public void Add(T item) => _items.Add(item);
    public T Create() => new T();          // 有 new() 约束才能这样写
}

Console.WriteLine(Max(3, 7));              // 7
Console.WriteLine(Max("aa", "ab"));        // ab
```

> **注意**：`new()` 约束必须放在约束列表最后；`struct` 约束隐含 `new()`，但不能同时写 `struct, new()`。

#### 8. 迭代器与 yield return

`yield return` 让编译器生成状态机：每取一个元素才执行一段，天然惰性、不用一次性建集合。

```csharp
static IEnumerable<int> Fibonacci(int count)
{
    int a = 0, b = 1;
    for (int i = 0; i < count; i++)
    {
        yield return a;                 // 惰性产出，每次调用前进一格
        (a, b) = (b, a + b);
    }
}

foreach (int n in Fibonacci(5))
{
    Console.Write($"{n} ");             // 0 1 1 2 3
}
```

- `foreach` 会调用 `GetEnumerator()`，对 `List<T>` 用的是 `struct` 枚举器，不装箱
- 迭代器方法体在第一次 `MoveNext()` 时才真正开始执行
- `yield break` 提前结束；迭代器方法不能有 `out` / `ref` 参数

#### 9. 遍历时修改集合

```csharp
var list = new List<int> { 1, 2, 3 };

try
{
    foreach (int n in list)
    {
        if (n == 2) list.Remove(n);     // 抛 InvalidOperationException
    }
}
catch (InvalidOperationException ex)
{
    Console.WriteLine($"遍历时不能修改：{ex.Message}");
}

for (int i = list.Count - 1; i >= 0; i--)   // ✅ 倒序 for 删除
{
    if (list[i] == 2) list.RemoveAt(i);
}
Console.WriteLine(list.RemoveAll(n => n == 1));   // ✅ RemoveAll 返回删除个数：1
```

> **注意**：`List<T>` 内部有 `_version` 计数器，`foreach` 的枚举器每步都检查它，任何增删都会让版本号变化并抛 `InvalidOperationException`。要边遍历边删，用倒序 `for`、`RemoveAll`，或先 `ToArray()` 复制一份。

#### 10. 常用操作复杂度

| 操作 | `List<T>` | `Dictionary<K,V>` | `HashSet<T>` | `LinkedList<T>` |
|------|-----------|-------------------|--------------|-----------------|
| 按索引/键访问 | `O(1)` | `O(1)` 平均 | — | `O(n)` |
| 查找 `Contains` | `O(n)` | `O(1)` 平均 | `O(1)` 平均 | `O(n)` |
| 尾部追加 | `O(1)` 均摊 | `O(1)` 平均 | `O(1)` 平均 | `O(1)` |
| 中间插入/删除 | `O(n)` | — | — | `O(1)`（已持有节点） |
| 有序遍历 | `O(n)` | 无序 | 无序 | `O(n)` |

#### 11. 小结

| 知识点 | 关键结论 |
|--------|----------|
| 接口 | `IEnumerable<T>` → `ICollection<T>` → `IList<T>` / `IDictionary<K,V>` / `ISet<T>` |
| `List<T>` | 动态数组，索引快、中间增删慢，可预分配容量 |
| `Dictionary` | 哈希表，键唯一；取值用 `TryGetValue` |
| `HashSet<T>` | 去重与集合运算，判重靠 `Equals` + `GetHashCode` |
| `Queue` / `Stack` | FIFO / LIFO，空集合用 `TryDequeue` / `TryPop` |
| 泛型 | `where` 约束换来类型安全与零装箱 |
| `yield` | 惰性迭代器，按需计算、省内存 |
| 遍历 | 遍历中不要增删；倒序 `for` 或 `RemoveAll` |
