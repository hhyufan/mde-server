# 数组

#### 1. 数组概述

##### 1.1 什么是数组

`数组`用来存放 `一组相同类型` 的元素，长度在建时确定、之后 `不可变`。

- **连续内存**：元素地址相邻，按索引随机访问是 `O(1)`
- **长度固定**：`Length` 只能读，扩容要新建数组（见 `Array.Resize`）
- **元素有默认值**：`int` 为 `0`、`bool` 为 `false`、引用类型为 `null`

##### 1.2 数组是引用类型

数组变量存的是 `堆上数组对象的引用`：赋值、传参复制的都是引用，方法内改元素会 `影响原数组`；但方法内重新 `new` 只改本地变量。

```csharp
static void Fill(int[] target)
{
    target[0] = 999;              // 改的是同一个数组对象
    target = new int[3];          // 重新赋值只影响本地变量
    target[0] = 1;
}

int[] nums = { 0, 0, 0 };
Fill(nums);
Console.WriteLine(nums[0]);       // 999
```

#### 2. 数组的创建

##### 2.1 声明与初始化

```csharp
// 1. new + 长度：元素取默认值
int[] empty = new int[3];                    // 0, 0, 0

// 2. 集合初始化器（声明时才能省略 new）
int[] nums = { 1, 2, 3, 4, 5 };

// 3. 显式 new + 初始化器
string[] names = new string[] { "Tom", "Jerry" };

// 4. 省略元素类型，由编译器推断
var flags = new[] { true, false };

// 5. 先声明后赋值：必须 new，不能用 { } 简写
int[] later;
later = new int[2];

Console.WriteLine($"{nums.Length} {names[1]} {flags[1]} {empty[2]} {later.Length}");
```

> **注意**：`int[] a = new int[3] { 1, 2, 3 };` 是合法的；但 `new int[3]` 后面不能再跟 `{ }` 里数量不符的元素，长度与初始化器数量必须一致。

##### 2.2 默认值

```csharp
int[] scores = new int[3];              // 0
bool[] switches = new bool[2];          // false
string?[] tags = new string?[2];        // null
DateTime[] dates = new DateTime[1];     // 0001-01-01 00:00:00

Console.WriteLine($"{scores[0]} {switches[0]} {tags[0] is null} {dates[0]:yyyy-MM-dd}");

// 数组变量本身是引用，没 new 就是 null
int[]? notReady = null;
try { Console.WriteLine(notReady![0]); }
catch (NullReferenceException) { Console.WriteLine("数组本身是 null"); }
```

#### 3. 访问与遍历

##### 3.1 Length 与索引

```csharp
int[] arr = { 10, 20, 30 };

Console.WriteLine(arr.Length);          // 3，合法索引 0 ~ 2
Console.WriteLine(arr[0]);              // 10
Console.WriteLine(arr[^1]);             // 30，末尾索引运算符（C# 8+）
Console.WriteLine(arr[^2]);             // 20

arr[0] = 100;                           // 索引表达式可作左值
Console.WriteLine(arr[0]);

try
{
    Console.WriteLine(arr[3]);          // IndexOutOfRangeException
}
catch (IndexOutOfRangeException ex)
{
    Console.WriteLine($"越界：{ex.Message}");
}
```

> **注意**：`Length` 是属性，`GetLength(int dim)` 是多维数组按维取值的方法，两者不要混用——一维数组上写 `GetLength(0)` 也行，但可读性差。

##### 3.2 遍历

```csharp
int[] nums = { 3, 1, 4, 1, 5 };

for (int i = 0; i < nums.Length; i++)   // 需要索引或要修改元素
{
    nums[i] *= 2;
}

int sum = 0;
foreach (int n in nums)                 // 只读遍历，最简洁
{
    sum += n;
}

Array.ForEach(nums, n => Console.Write($"{n} "));   // 委托式遍历
Console.WriteLine($"\nsum = {sum}");

// foreach 的迭代变量是只读副本，修改它不会写回数组
// foreach (int n in nums) { n = 0; }   // 编译错误 CS1656
```

#### 4. 多维数组与交错数组

##### 4.1 多维数组 `[,]`

```csharp
int[,] grid =
{
    { 1, 2, 3 },
    { 4, 5, 6 },
};

Console.WriteLine(grid[1, 2]);             // 6
Console.WriteLine(grid.Rank);              // 2，维数
Console.WriteLine(grid.Length);            // 6，元素总数
Console.WriteLine(grid.GetLength(0));      // 2，第 0 维长度
Console.WriteLine(grid.GetLength(1));      // 3
Console.WriteLine(grid.GetUpperBound(0));  // 1，第 0 维最大索引

for (int i = 0; i < grid.GetLength(0); i++)
{
    for (int j = 0; j < grid.GetLength(1); j++)
    {
        Console.Write($"{grid[i, j]} ");
    }
    Console.WriteLine();
}
```

##### 4.2 交错数组 `[][]`

```csharp
// 数组的数组：每行长度可以不同
int[][] jagged = new int[3][];
jagged[0] = new[] { 1 };
jagged[1] = new[] { 2, 3 };
jagged[2] = new[] { 4, 5, 6 };

Console.WriteLine(jagged.Length);         // 3，行数
Console.WriteLine(jagged[2].Length);      // 3，第 3 行长度

foreach (int[] row in jagged)
{
    Console.WriteLine(string.Join(",", row));
}

// 一步完成初始化
int[][] quick = { new[] { 1, 2 }, new[] { 3 } };
Console.WriteLine(quick[0][1]);           // 2
```

| 对比项 | 多维 `[,]` | 交错 `[][]` |
|--------|-----------|------------|
| 内存 | 一整块连续区域 | 每行是独立数组 |
| 行长 | 必须相同 | 可以不同 |
| 取长度 | `GetLength(dim)` | `arr[i].Length` |
| 分配 | `new int[2, 3]` 一次完成 | 先 `new int[3][]`，再逐行 `new` |

#### 5. Array 静态类

##### 5.1 排序与查找

```csharp
int[] data = { 5, 2, 8, 1, 9 };

Array.Sort(data);                             // 原地升序
Console.WriteLine(string.Join(",", data));    // 1,2,5,8,9

Array.Reverse(data);                          // 反转
Console.WriteLine(string.Join(",", data));    // 9,8,5,2,1

Console.WriteLine(Array.IndexOf(data, 5));    // 2
Console.WriteLine(Array.IndexOf(data, 100));  // -1，找不到返回 -1

Array.Sort(data);
Console.WriteLine(Array.BinarySearch(data, 5));   // 2，必须先升序

Array.Clear(data, 0, 2);                      // 把 [0,2) 置为默认值
Console.WriteLine(string.Join(",", data));    // 0,0,5,8,9

Array.Sort(data, (a, b) => b.CompareTo(a));    // 自定义比较：降序
```

##### 5.2 复制与扩容

```csharp
int[] src = { 1, 2, 3, 4 };

int[] part = new int[2];
Array.Copy(src, 1, part, 0, 2);               // src[1] 起 2 个 → part
Console.WriteLine(string.Join(",", part));    // 2,3

int[] copy = (int[])src.Clone();              // 浅复制成新数组
copy[0] = 100;
Console.WriteLine(src[0]);                    // 1，原数组不受影响

Array.Resize(ref src, 6);                     // 内部新建 + 复制，需 ref
Console.WriteLine(string.Join(",", src));     // 1,2,3,4,0,0
Console.WriteLine(src.Length);                // 6
```

> **性能提示**：`Array.Resize` 名字有误导性——它 `不会` 修改原数组对象，而是新建一个数组并把引用赋回变量。循环里频繁 `Resize` 是 `O(n²)`，应改用 `List<T>`。

#### 6. 数组协变

```csharp
// 引用类型数组协变：string[] 可以赋给 object[]
object[] objs = new string[2];

try
{
    objs[0] = 123;              // 编译通过，运行时抛 ArrayTypeMismatchException
}
catch (ArrayTypeMismatchException)
{
    Console.WriteLine("数组协变只允许安全读取，写入不兼容类型会抛异常");
}

string[] strs = { "a", "b" };
object[] cov = strs;            // 同一个数组，两种视图
Console.WriteLine(cov[1]);      // b

// 值类型数组不参与协变
// object[] nums = new int[3];   // 编译错误 CS0029
```

> **注意**：数组协变是 `不安全` 的历史设计。需要"只读的多类型视图"时用 `IReadOnlyList<object>` 或 `IEnumerable<object>`，避免运行期的 `ArrayTypeMismatchException`。

#### 7. Span\<T\> 与 stackalloc

```csharp
// stackalloc：在栈上分配，不经过 GC
Span<int> buffer = stackalloc int[4];
for (int i = 0; i < buffer.Length; i++)
{
    buffer[i] = i * i;
}

// Span<T> 是任意连续内存的切片视图，零拷贝
int[] arr = { 1, 2, 3, 4, 5 };
Span<int> slice = arr.AsSpan(1, 3);   // 从索引 1 起 3 个
slice[0] = 200;                        // 直接改原数组
Console.WriteLine(string.Join(",", arr));            // 1,200,3,4,5
Console.WriteLine(string.Join(",", buffer.ToArray()));

ReadOnlySpan<char> head = "Hello World".AsSpan(0, 5);
Console.WriteLine(head.ToString());              // Hello
```

- `Span<T>` 只能存在于栈上，不能作为 `async` 方法里的局部变量
- 需要跨 `await` 时改用 `Memory<T>`
- 热路径上处理数组片段（解析、序列化）用 `Span` 可免掉 `Substring` / `Copy` 的分配

#### 8. 小结

| 知识点 | 关键结论 |
|--------|----------|
| 创建 | `new T[n]` 取默认值；`{ }` 只能在声明时省略 `new` |
| 长度 | `Length` 元素总数；多维用 `GetLength(dim)` / `GetUpperBound(dim)` |
| 越界 | 抛 `IndexOutOfRangeException`，不用返回值表示 |
| 遍历 | `for` 可写，`foreach` 只读，`Array.ForEach` 委托式 |
| 二维 | `[,]` 矩形连续；`[][]` 交错灵活 |
| API | `Sort` / `Reverse` / `IndexOf` / `BinarySearch` / `Clear` / `Copy` / `Resize` |
| 协变 | 引用类型数组可协变，写入不兼容类型抛 `ArrayTypeMismatchException` |
| 高性能 | `Span<T>` + `stackalloc` 避免堆分配与拷贝 |
