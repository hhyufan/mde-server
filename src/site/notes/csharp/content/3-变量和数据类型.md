# 变量和数据类型

#### 1. 变量

##### 1.1 变量的作用

`变量`是用来 `保存数据`的，`数据`保存在 `内存中`。C# 是 `强类型`语言：变量在声明时必须确定 `类型`，之后只能存该类型的值。

变量由三要素构成：

- **类型**：决定占多少内存、能参与哪些运算
- **名称**：标识符，用于在代码中引用
- **值**：内存中实际存放的数据

##### 1.2 变量的声明与赋值

```csharp
// 1. 先声明，后赋值
int age;
age = 22;

// 2. 声明的同时赋值
int height = 180;

// 3. 同时声明多个同类型变量并赋值
int length = 100, width = 50, depth = 25;

// 4. 赋值可以基于表达式
int total = length * width * depth;

Console.WriteLine($"age = {age}, height = {height}");
Console.WriteLine($"体积 = {total}");
```

> **注意**：局部变量 `必须赋值后才能使用`，否则编译报错 `CS0165 Use of unassigned local variable`。这一点和字段不同，字段会取类型默认值。

##### 1.3 标识符的命名规则与规范

标识符：程序中 `自定义`的名称，例如 `变量名`、`方法名`、`类名`。

> - **命名规则（硬性，违反则编译失败）**
>   - 由字母、数字、下划线 `_` 组成，`@` 可作为前缀
>   - 不允许以数字开头
>   - 严格区分大小写（`age` 和 `Age` 是两个变量）
>   - 不能使用关键字；确需使用时加 `@` 转义，如 `@class`
> - **命名规范（软性，团队约定）**
>   - 局部变量、方法参数：小驼峰 `camelCase`
>   - 私有字段：下划线开头 `_camelCase`
>   - 类、方法、属性、常量：大驼峰 `PascalCase`
>   - 接口：`I` 前缀，如 `IDisposable`
>   - 常量：C# 惯例是 `PascalCase`，而不是 Java 的 `UPPER_CASE`

```csharp
public class UserService
{
    // 私有字段：下划线 + 小驼峰
    private readonly string _connectionString;

    // 常量：大驼峰
    public const int MaxRetryCount = 3;

    // 属性：大驼峰
    public string Name { get; set; }

    public UserService(string connectionString)
    {
        _connectionString = connectionString;
    }

    // 方法：大驼峰；参数：小驼峰
    public void SendMail(string toAddress, int retryCount = MaxRetryCount)
    {
        var localCopy = toAddress.Trim();   // 局部变量：小驼峰
        Console.WriteLine(localCopy);
    }
}
```

#### 2. 数据类型

##### 2.1 值类型与引用类型

C# 的类型分为两大类，区别在于 `数据存在哪` 和 `赋值时复制什么`。

| 分类 | 包含 | 存储位置 | 赋值行为 |
|------|------|----------|----------|
| 值类型 | 基元类型（`int`/`double`/`bool`/`char`）、`struct`、`enum` | 栈，或作为字段内联在对象中 | 复制整个值 |
| 引用类型 | `class`、`interface`、`array`、`delegate`、`string`、`object` | 堆（变量本身存引用） | 复制引用（两个变量指向同一对象） |

```csharp
struct Point { public int X; }

class Person { public string Name = ""; }

// 值类型：赋值即复制
var p1 = new Point { X = 1 };
var p2 = p1;
p2.X = 2;
Console.WriteLine(p1.X);   // 1，互不影响

// 引用类型：赋值即共享同一对象
var a = new Person { Name = "Tom" };
var b = a;
b.Name = "Jerry";
Console.WriteLine(a.Name); // Jerry，a 和 b 指向同一对象
```

> **`string` 是特例**：它是引用类型，但 `不可变`，任何"修改"都会产生新对象，所以表现得更像值类型。

##### 2.2 整数类型

| 类型 | 字节 | 范围 | 字面量后缀 |
|------|------|------|------------|
| `sbyte` | 1 | -128 ~ 127 | 无 |
| `byte` | 1 | 0 ~ 255 | 无 |
| `short` | 2 | -32,768 ~ 32,767 | 无 |
| `ushort` | 2 | 0 ~ 65,535 | 无 |
| `int` | 4 | -2,147,483,648 ~ 2,147,483,647 | 无（整数默认 `int`） |
| `uint` | 4 | 0 ~ 4,294,967,295 | `u` / `U` |
| `long` | 8 | ±9.22×10<sup>18</sup> | `L` / `l` |
| `ulong` | 8 | 0 ~ 1.84×10<sup>19</sup> | `UL` |

- 未加后缀的整数字面量默认是 `int`；超出 `int` 范围会编译报错，必须加 `L`
- `nint` / `nuint` 是平台相关宽度的整数（32 位系统 4 字节，64 位系统 8 字节）

##### 2.3 浮点类型与 decimal

| 类型 | 字节 | 有效数字 | 后缀 | 适用场景 |
|------|------|----------|------|----------|
| `float` | 4 | 约 7 位 | `f` / `F` | 图形、科学计算 |
| `double` | 8 | 约 15~17 位 | `d` / `D`（默认） | 通用浮点运算 |
| `decimal` | 16 | 约 28~29 位 | `m` / `M` | `金额`、财务计算 |

浮点数用 `二进制`存储，`0.1` 这类十进制小数无法精确表示，所以**永远不要用 `==` 比较浮点数**。涉及金额时用 `decimal`。

```csharp
double d = 0.1 + 0.2;
Console.WriteLine(d);                 // 0.30000000000000004
Console.WriteLine(d == 0.3);          // False

decimal m = 0.1m + 0.2m;
Console.WriteLine(m);                 // 0.3
Console.WriteLine(m == 0.3m);         // True

// 浮点数比较应使用误差范围
bool nearlyEqual = Math.Abs(d - 0.3) < 1e-10;
Console.WriteLine(nearlyEqual);       // True

// float 必须带后缀，否则类型不匹配
float f = 1.5f;
Console.WriteLine(f);
```

##### 2.4 布尔类型

- 只有 `true` 和 `false` 两个字面量，占 1 字节
- **不能**用 `0` / `1` 当布尔值，`if (1)` 直接编译报错，这一点比 C/C++ 严格

##### 2.5 字符与字符串

- `char`：单个字符，`单引号`包裹，2 字节，存 `UTF-16` 码元
- `string`：字符序列，`双引号`包裹，引用类型但不可变

```csharp
char c = 'A';
Console.WriteLine((int)c);      // 65，char 与 int 可互转

// 转义字符
Console.WriteLine("aa\nbb");    // 换行
Console.WriteLine("aa\tbb");    // 制表符
Console.WriteLine("路径：C:\\Notes");

// 逐字字符串 @：不解析转义，可跨行
Console.WriteLine(@"C:\Notes\CSharp");
Console.WriteLine(@"第一行
第二行");

// 原始字符串（C# 11+）：三引号，内部无需转义
Console.WriteLine("""他说："C:\Notes" 是路径""");

// 字符串插值
string name = "张三";
int age2 = 18;
Console.WriteLine($"{name} 今年 {age2} 岁，明年 {age2 + 1} 岁");
```

##### 2.6 默认值

字段、数组元素会被自动初始化为 `default`；局部变量不会，必须手动赋值。

```csharp
int[] arr = new int[3];
Console.WriteLine(arr[0]);          // 0

bool flag = default;                // false
int zero = default;                 // 0
string? text = default;             // null

// Console.WriteLine(localInt);     // 编译错误：使用了未赋值的局部变量
```

#### 3. var 与类型推断

`var` 不是"动态类型"，它只是让 `编译器`根据右侧表达式推断类型，编译后类型完全确定。

```csharp
var count = 10;                       // 推断为 int
var price = 9.9m;                     // 推断为 decimal
var list = new List<string>();        // 推断为 List<string>
var dict = new Dictionary<string, int>();

// var v;                             // 错误：必须同时初始化
// count = "abc";                     // 错误：count 已经是 int

Type t = count.GetType();
Console.WriteLine(t.Name);            // Int32，说明是静态类型
```

**使用建议**：

- 右侧类型一眼可见时用 `var`（如 `new List<int>()`、LINQ 查询）
- 右侧类型不明显时写出类型，如 `var result = GetData();` 建议写成 `List<User> result = ...`

#### 4. 可空类型与 null

##### 4.1 可空值类型

值类型默认不能为 `null`，加 `?` 变成 `Nullable<T>`，用于表达"可能没有值"。

```csharp
int? maybeAge = null;
Console.WriteLine(maybeAge.HasValue);     // False
Console.WriteLine(maybeAge ?? 0);         // 0，?? 提供默认值

maybeAge = 20;
if (maybeAge is int age)
{
    Console.WriteLine(age);               // 20，模式匹配顺带判空
}

// int x = maybeAge;                     错误：int? 不能隐式转 int
int y = maybeAge.Value;                   // 确定有值时才可用 Value
int z = (int)maybeAge;                    // 显式转换，null 时抛异常
```

##### 4.2 可空引用类型（C# 8+）

项目开启 `<Nullable>enable</Nullable>` 后，`string` 表示"不应为 null"，`string?` 表示"可能为 null"，编译器会给出警告。

```csharp
string  name = "Tom";     // 非空引用
string? nick = null;      // 可能为 null

// 空条件运算符 ?. 与空合并赋值 ??=
Console.WriteLine(nick?.Length);          // 输出空行，不抛异常
nick ??= "无名";
Console.WriteLine(nick.Length);           // 3

// 空包容运算符 !：告诉编译器"我确定不为 null"
string forced = nick!;
```

#### 5. 常量与只读

| 关键字 | 赋值时机 | 能否改 | 适用位置 |
|--------|----------|--------|----------|
| `const` | `编译期`常量，必须是字面量或字面量表达式 | 不能 | 字段、局部变量 |
| `readonly` | `运行期`，在声明处或构造函数中赋值一次 | 不能 | 字段 |
| `static` | 类型级别，全类型共享一份 | 可改 | 字段、属性、方法 |

```csharp
public class Order
{
    public const double TaxRate = 0.13;              // 编译期常量
    public static readonly DateTime CreatedAt = DateTime.Now;  // 运行期只读

    private readonly List<string> _items = new();

    public Order()
    {
        // _items = new List<string>();  // 构造函数里可以再赋一次
    }
}

Console.WriteLine(Order.TaxRate);
Console.WriteLine(Order.CreatedAt);
```

> `const` 会被"内联"到调用方程序集：如果别的项目引用了这个常量，重新编译那个库后，调用方需重新编译才能拿到新值。`readonly` 没有这个问题。

#### 6. 类型转换

##### 6.1 隐式转换与显式转换

- **隐式**：小范围 → 大范围，不会丢数据，编译器自动完成
- **显式**：大范围 → 小范围，需要 `(类型)` 强转，可能丢精度

```csharp
// 隐式：byte -> short -> int -> long -> float -> double
int i = 100;
long l = i;
double d = i;

// 显式：截断小数部分，不四舍五入
double pi = 3.99;
int truncated = (int)pi;              // 3
Console.WriteLine(truncated);

// 需求四舍五入要用 Math.Round / Convert
Console.WriteLine(Math.Round(pi));    // 4
Console.WriteLine(Convert.ToInt32(pi)); // 4
```

##### 6.2 checked 与 unchecked

整型溢出默认 `不检查`（`unchecked`），会静默回绕。需要检查时用 `checked`。

```csharp
byte b;

unchecked
{
    b = (byte)300;                    // 静默回绕：300 - 256 = 44
    Console.WriteLine(b);             // 44
}

try
{
    checked { b = (byte)300; }        // 抛 OverflowException
}
catch (OverflowException)
{
    Console.WriteLine("溢出被捕获");
}
```

##### 6.3 字符串与数值互转

三种方式，**优先用 `TryParse`**：解析失败不抛异常，只返回 `false`。

```csharp
string input = "123";

// 1. Parse：失败抛 FormatException
int n1 = int.Parse(input);

// 2. Convert：失败抛异常，null 会转成 0
int n2 = Convert.ToInt32(input);
int n3 = Convert.ToInt32(null);       // 0

// 3. TryParse：失败返回 false，最安全
bool ok = int.TryParse("abc", out int value);
Console.WriteLine($"{ok}, {value}");  // False, 0

// 数值转字符串
Console.WriteLine(123.ToString());
Console.WriteLine(123.ToString("N2"));      // 123.00，千分位
Console.WriteLine(123.ToString("X"));       // 7B，十六进制
Console.WriteLine(3.14159.ToString("F2"));  // 3.14
```

#### 7. 装箱与拆箱

- **装箱**：值类型 → `object`，在堆上分配新对象并复制值
- **拆箱**：`object` → 值类型，检查类型后复制回栈

```csharp
int n = 42;
object boxed = n;        // 装箱：堆上新建一个 int 副本
n = 100;                 // 修改原值，箱子里的值不变
Console.WriteLine(boxed);   // 42

int unboxed = (int)boxed;   // 拆箱：必须类型完全匹配
Console.WriteLine(unboxed); // 42

// 拆箱到错误类型会抛 InvalidCastException
try { long bad = (long)boxed; }
catch (InvalidCastException) { Console.WriteLine("拆箱类型不匹配"); }
```

> **性能提示**：装箱/拆箱有堆分配和类型检查开销。泛型 `List<int>` 不装箱，非泛型 `ArrayList` 每次 `Add(int)` 都会装箱——这是泛型存在的重要理由之一。

#### 8. 小结

| 知识点 | 关键结论 |
|--------|----------|
| 值类型 vs 引用类型 | 赋值时分别复制 `值` 与 `引用` |
| `decimal` | 金额等精确十进制场景使用，避免 `double` 误差 |
| `var` | 编译期推断，仍是静态类型 |
| 可空 | `int?` 用 `HasValue`/`??`；引用类型开启 `Nullable` 后区分 `string` 与 `string?` |
| 转换 | 优先 `TryParse`，失败不抛异常 |
| 装箱 | 泛型可避免，性能敏感处留意 |
