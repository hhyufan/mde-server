# 流程控制语句

#### 1. 三种基本结构

- **顺序**：自上而下逐条执行
- **分支**：`if`、`switch`
- **循环**：`for`、`foreach`、`while`、`do-while`

#### 2. if 语句

```csharp
int score = 86;

if (score >= 90)
{
    Console.WriteLine("优秀");
}
else if (score >= 60)
{
    Console.WriteLine("及格");
}
else
{
    Console.WriteLine("不及格");
}
```

- 条件必须是 `bool`，不能写 `if (1)`
- `else if` 从上到下匹配，命中后其余分支跳过
- `else` 就近匹配；单条语句也建议保留大括号
- 嵌套过深时用逻辑运算符合并，或用卫语句提前 `return`

#### 3. switch 语句

```csharp
int state = 2;

switch (state)
{
    case 0:
        Console.WriteLine("开始");
        break;
    case 1:
    case 2:
        Console.WriteLine("进行中");
        break;
    default:
        Console.WriteLine("未知状态");
        break;
}
```

- `case` 后必须是编译期常量，且不能重复；多个 `case` 可共用分支
- C# **不允许**隐式贯穿，分支必须以 `break` / `return` / `goto` 结束
- 支持 `int`、`char`、`string`、枚举等类型，也支持 `when` 条件
- `default` 可省略；`goto case 常量` 可跳到其他分支，少用

#### 4. switch 表达式

```csharp
int score = 86;
string level = score switch
{
    >= 90 => "优秀",
    >= 60 => "及格",
    _ => "不及格",
};
Console.WriteLine(level);

string Describe(object? value) => value switch
{
    null => "空值",
    int n => $"整数 {n}",
    string { Length: 0 } => "空字符串",
    string s => $"字符串 {s}",
    _ => "其他类型",
};
Console.WriteLine(Describe(-3));
```

- 整体是一个表达式，可直接赋值或返回
- `_` 兜底；没有覆盖所有情况时编译器给出警告
- 常用模式：常量、关系（`>= 90`）、类型（`int n`）、属性（`{ Length: 0 }`）
- `when` 在模式后追加条件；分支从上到下匹配，宽泛的模式放后面

#### 5. for 循环

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.Write($"{i} ");
}
Console.WriteLine();

int j = 0;
for (; j < 3;)
{
    Console.WriteLine($"j = {j}");
    j++;
}
```

- 三段都可省略，`for (;;)` 是死循环，靠 `break` / `return` 退出
- 循环变量作用域仅限循环内部
- 适合已知次数或需要索引的场景

#### 6. foreach 循环

```csharp
string[] fruits = { "苹果", "香蕉", "橙子" };
foreach (string fruit in fruits)
{
    Console.WriteLine(fruit);
}

var scores = new Dictionary<string, int> { ["语文"] = 90, ["数学"] = 95 };
foreach (var (subject, score) in scores)
{
    Console.WriteLine($"{subject}: {score}");
}
```

- 可遍历数组、`List<T>`、`Dictionary<TKey,TValue>` 及任何 `IEnumerable`
- 本质是调用 `GetEnumerator()`，依次取 `Current`、`MoveNext()`
- 迭代变量只读；遍历中增删集合会抛 `InvalidOperationException`
- 只读遍历优先用 `foreach`，需要索引或倒序时用 `for`

#### 7. while 与 do-while

```csharp
int number;
string? input;
do
{
    Console.Write("请输入 1~100：");
    input = Console.ReadLine();
}
while (!int.TryParse(input, out number) || number is < 1 or > 100);

int sum = 0;
int i = 1;
while (i <= 100)
{
    sum += i;
    i++;
}
Console.WriteLine($"1~100 的和 = {sum}");
```

- `while` 先判断后执行，可能一次都不执行
- `do-while` 先执行一次再判断，至少执行一次，结尾有分号
- 次数未知、依赖输入时优先用 `while`
- 确保条件最终变为 `false`，否则死循环

#### 8. 跳转语句

```csharp
for (int i = 0; i < 6; i++)
{
    if (i == 2)
    {
        continue;          // 跳过本次
    }
    if (i == 5)
    {
        break;             // 结束循环
    }
    Console.Write($"{i} ");
}
Console.WriteLine();

for (int i = 0; i < 3; i++)
{
    for (int j = 0; j < 3; j++)
    {
        if (i * j > 2)
        {
            goto done;     // 一次跳出两层
        }
    }
}
done:
Console.WriteLine("跳出嵌套循环");

if (args.Length == 0)
{
    return;                // 结束顶层语句
}
Console.WriteLine(args[0]);
```

- `break` 结束最近一层循环或 `switch`；`continue` 跳过本次迭代
- `return` 结束方法（顶层语句中结束程序）
- C# 没有带标签的 `break`，跳出多层用 `goto` 或标志变量
- `goto` 只能跳到同一方法内的标签，不能跳入循环体，慎用

#### 9. 嵌套循环与经典算法

##### 9.1 九九乘法表

```csharp
for (int i = 1; i <= 9; i++)
{
    for (int j = 1; j <= i; j++)
    {
        Console.Write($"{j}×{i}={i * j,2}\t");
    }
    Console.WriteLine();
}
```

- 外层控制行，内层控制列；`j <= i` 形成下三角
- `{i * j,2}` 表示右对齐占 2 列

##### 9.2 判断素数

```csharp
Console.WriteLine(IsPrime(97));
Console.WriteLine(IsPrime(91));

static bool IsPrime(int n)
{
    if (n < 2)
    {
        return false;
    }

    for (int i = 2; i * i <= n; i++)
    {
        if (n % i == 0)
        {
            return false;
        }
    }
    return true;
}
```

- 只需试除到 `√n`：若 `n = a × b`，必有一个因子 ≤ `√n`
- 时间复杂度从 `O(n)` 降到 `O(√n)`

> **性能提示**：嵌套循环是性能热点，内层尽量做常数级工作；数据量大时考虑 `HashSet`、排序或提前 `break`。

#### 10. 小结

| 结构 | 适用场景 | 关键点 |
|------|----------|--------|
| `if` / `else` | 区间判断 | 条件必须是 `bool` |
| `switch` 语句 | 等值匹配、枚举 | 不能隐式贯穿 |
| `switch` 表达式 | 模式匹配、返回值 | `_` 兜底，注意顺序 |
| `for` / `foreach` | 计次 / 只读遍历 | 遍历中不能改集合 |
| `while` / `do-while` | 次数未知 | `do-while` 至少执行一次 |
