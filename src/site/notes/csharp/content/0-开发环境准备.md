# 开发环境准备

#### 1. .NET 平台与 C#

##### 1.1 .NET 是什么

`.NET` 是一个免费、跨平台、开源的开发平台，由三部分组成：

- **运行时（CLR / CoreCLR）**：加载程序、管理内存、垃圾回收、异常与线程
- **基础类库（BCL）**：`System.*` 下的集合、IO、网络、JSON、加密等 API
- **SDK 与工具链**：`dotnet` CLI、C# 编译器（Roslyn）、项目模板

C# 只是“语言”，必须运行在 .NET 之上；同一套 .NET 还可以使用 F#、VB.NET。

##### 1.2 从源码到运行

1. `dotnet build` 调用 Roslyn，把 `.cs` 编译成 **IL（中间语言）**，产物是 `.dll`
2. 运行时加载 IL，由 **JIT** 在方法首次执行时编译成本机机器码
3. 也可以用 **AOT / ReadyToRun** 提前编译，减少启动时间

| 概念 | 职责 |
|------|------|
| C# | 编程语言，提供语法与类型系统 |
| IL / CIL | 编译器产出的中间语言 |
| CLR | 执行 IL、GC、异常、线程管理 |
| BCL | 标准库，提供常用 API |
| SDK | 编译、运行、打包、发布的一站式工具 |

##### 1.3 版本与选择

- **.NET 10**：当前 LTS（长期支持）版本，配套 C# 14
- **.NET 8**：上一代 LTS，仍有大量项目在使用，配套 C# 12
- **.NET Framework 4.8**：仅 Windows、只维护不演进，只有老项目会遇到
- **.NET Standard**：类库的兼容性规范，新项目一般不再指定

> **注意**：目标框架写在 `.csproj` 的 `<TargetFramework>` 中。`net10.0` 与 `net8.0` 可用的语法和 API 有差异，抄代码前先确认项目框架。

#### 2. 安装 .NET SDK

##### 2.1 下载与安装

- 官网：<https://dotnet.microsoft.com/download>
- Windows 也可以用包管理器：`winget install Microsoft.DotNet.SDK.10`
- 必须安装 **SDK**（不是只装 Runtime），否则没有 `dotnet new`、`dotnet build`
- 安装路径不要包含中文或特殊符号

##### 2.2 验证安装

打开新的终端（让 `PATH` 生效），执行：

```bash
dotnet --version
dotnet --list-sdks
dotnet --list-runtimes
dotnet --info
```

输出示例（版本号以本机为准）：

```text
.NET SDK:
 Version:           10.0.100
 Commit:            xxxxxxx
 Workload version:  10.0.100-manifests.xxxxxxx

Runtime Environment:
 OS Name:     Windows
 OS Version:  10.0.26100
 OS Platform: Windows
 RID:         win-x64
 Base Path:   C:\Program Files\dotnet\sdk\10.0.100\

Host:
  Version:      10.0.0
  Architecture: x64
```

- `--list-sdks` 有输出，说明可以**编译**
- `--list-runtimes` 有输出，说明可以**运行**
- `--info` 同时给出 RID 与安装路径，排查问题时先看它
- 一台机器可以并存多个 SDK；项目根目录的 `global.json` 可以锁定版本

#### 3. 第一个控制台项目

##### 3.1 创建并运行

```bash
dotnet new console -n HelloCSharp
cd HelloCSharp
dotnet run
```

- `dotnet new console` 使用控制台模板，生成 `HelloCSharp.csproj` 与 `Program.cs`
- `dotnet run` 会隐式执行 `restore`（还原 NuGet）→ `build` → 运行
- 首次运行输出 `Hello, World!`

##### 3.2 顶层语句

C# 9 起支持**顶层语句**：不必手写 `class Program` 和 `static void Main`，编译器会自动生成入口方法。

```csharp
// Program.cs
Console.WriteLine("Hello, C#!");
Console.WriteLine($"当前运行时：{Environment.Version}");
Console.WriteLine($"操作系统：{Environment.OSVersion}");
```

- 一个项目只能有一个文件使用顶层语句
- 顶层语句必须写在类型声明之前
- 顶层语句中的 `args` 就是命令行参数数组

##### 3.3 接收命令行参数

```csharp
// dotnet run -- 张三 20
string name = args.Length > 0 ? args[0] : "匿名";
int age = args.Length > 1 && int.TryParse(args[1], out int parsed) ? parsed : 0;

Console.WriteLine($"你好，{name}！");
Console.WriteLine($"明年你 {age + 1} 岁");
```

`--` 之后的参数才会传给程序，否则会被 `dotnet run` 自己解析。

#### 4. 项目结构

##### 4.1 目录说明

| 路径 | 作用 | 是否提交到 Git |
|------|------|----------------|
| `Program.cs` | 入口代码 | 是 |
| `HelloCSharp.csproj` | 项目配置 | 是 |
| `obj/` | 还原与编译的中间文件 | 否 |
| `bin/` | 编译输出 | 否 |
| `Properties/launchSettings.json` | 启动配置（环境变量、参数） | 视团队约定 |

##### 4.2 .csproj 文件

```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>

</Project>
```

- `OutputType=Exe`：生成可执行程序；类库则是 `Library`
- `TargetFramework`：目标框架，决定可用 API 与默认 C# 版本
- `ImplicitUsings`：自动引入 `System`、`System.Linq` 等常用命名空间
- `Nullable`：开启可空引用类型检查，详见“编码规范”一章

##### 4.3 构建与输出

```bash
dotnet build
dotnet build -c Release
dotnet run -c Release
```

- 默认输出到 `bin/Debug/net10.0/`
- Windows 下会生成 `HelloCSharp.exe` 和 `HelloCSharp.dll`，真正托管代码在 `.dll` 里
- `dotnet clean` 清理输出；`dotnet publish` 生成可部署文件

#### 5. NuGet 包管理

NuGet 是 .NET 的包管理器，类似 Java 的 Maven Central，包页在 <https://www.nuget.org>。

```bash
dotnet add package Newtonsoft.Json
dotnet list package
dotnet restore
```

- `dotnet add package` 会修改 `.csproj`，添加 `<PackageReference Include="..." Version="..." />`
- 不写版本则取最新稳定版；生产项目建议显式锁定版本
- `dotnet restore` 按 `.csproj` 还原依赖，CI 中常单独执行
- 包缓存在 `%USERPROFILE%\.nuget\packages`，可用 `dotnet nuget locals all --clear` 清理

> **提示**：.NET 自带 `System.Text.Json`，新项目做 JSON 序列化不必急着安装 Newtonsoft.Json。

#### 6. 运行环境自检

需要确认“代码到底跑在哪个运行时”时，直接打印：

```csharp
using System.Runtime.InteropServices;

Console.WriteLine($"框架：{RuntimeInformation.FrameworkDescription}");
Console.WriteLine($"架构：{RuntimeInformation.ProcessArchitecture}");
Console.WriteLine($".NET 版本：{Environment.Version}");
Console.WriteLine($"是否 64 位进程：{Environment.Is64BitProcess}");
```

#### 7. 小结

| 主题 | 关键结论 |
|------|----------|
| 平台 | C# 编译为 IL，由 CLR 执行；.NET 10 为当前 LTS |
| 安装 | 装 SDK 而非仅 Runtime，用 `dotnet --info` 验证 |
| 项目 | `dotnet new console -n 名称`，`dotnet run` 一键运行 |
| 结构 | `.csproj` 管配置，`bin/`、`obj/` 不入库 |
| 依赖 | NuGet 包通过 `PackageReference` 管理 |
