# 运算符

#### 1. 算术运算符

- 运算符：`+`、`-`、`*`、`/`、`%`，以及自增 `++`、自减 `--`
- 两个整数相除结果仍是整数，小数部分直接截断
- 整数除以 0 抛 `DivideByZeroException`；浮点数除以 0 得到 `Infinity` 或 `NaN`
- `%` 的结果符号与被除数一致：`-10 % 3 == -1`
- 前置“先加后用”，后置“先用后加”

```csharp
int a = 10, b = 3;
Console.WriteLine(a / b);            // 3
Console.WriteLine(10.0 / b);         // 3.3333333333333335
Console.WriteLine(a % b);            // 1
Console.WriteLine(-10 % 3);          // -1

int i = 5;
Console.WriteLine(i++);              // 5
Console.WriteLine(i);                // 6
Console.WriteLine(++i);              // 7

int zero = 0;
try
{
    Console.WriteLine(a / zero);
}
catch (DivideByZeroException)
{
    Console.WriteLine("整数除零");
}
Console.WriteLine(10.0 / 0);         // Infinity
```

#### 2. 赋值运算符

- `=`、`+=`、`-=`、`*=`、`/=`、`%=`，以及位运算赋值 `&=`、`|=`、`^=`、`<<=`、`>>=`
- 复合赋值只对左侧求值一次，并自动完成窄化转换
- `??=` 仅在左侧为 `null` 时赋值

```csharp
int x = 10;
x += 5;      // 15
x %= 7;      // 5
Console.WriteLine(x);

byte b = 200;
b += 100;    // 等价于 b = (byte)(b + 100)
Console.WriteLine(b);      // 44

int? count = null;
count ??= 1;
Console.WriteLine(count);  // 1
```

#### 3. 比较运算符

- `==`、`!=`、`>`、`>=`、`<`、`<=`，结果一定是 `bool`
- `string` 重载了 `==`，比较内容；`ReferenceEquals` 比较是否同一对象
- 浮点数不要直接用 `==`，用误差范围或 `decimal`
- 重载 `==` 时通常同时重写 `Equals` / `GetHashCode`

```csharp
string s1 = "csharp";
string s2 = string.Concat("c", "sharp");
Console.WriteLine(s1 == s2);                  // True
Console.WriteLine(ReferenceEquals(s1, s2));   // False

double d = 0.1 + 0.2;
Console.WriteLine(d == 0.3);                  // False
Console.WriteLine(Math.Abs(d - 0.3) < 1e-10); // True
```

#### 4. 逻辑运算符

- `&&`、`||`、`!`，操作数必须是 `bool`
- `&&`、`||` 短路：左边能决定结果时右边不执行
- `&`、`|` 非短路；对整数则是按位运算；`^` 对 `bool` 是异或
- 空值判断依赖短路：`obj != null && obj.Length > 0`

```csharp
bool hasTicket = true, hasId = false;
Console.WriteLine(hasTicket && hasId);   // False
Console.WriteLine(hasTicket || hasId);   // True
Console.WriteLine(hasTicket ^ hasId);    // True

int count = 0;
bool r1 = false && ++count > 0;
bool r2 = false & ++count > 0;
Console.WriteLine($"count = {count}, r1 = {r1}, r2 = {r2}");
```

> **注意**：`&` 会执行右侧，判断空值时不要用它替换 `&&`。

#### 5. 位运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `&` `\|` `^` | 按位与、或、异或 | `0b1100 & 0b1010` → `0b1000` |
| `~` | 按位取反 | `~0` → `-1` |
| `<<` `>>` `>>>` | 左移、算术右移、逻辑右移 | `1 << 3` → 8 |

- `>>` 高位补符号位；`>>>`（C# 11+）高位补 0
- 位移位数按 5 位（`int`）或 6 位（`long`）取模：`1 << 33 == 2`
- 常用于 `[Flags]` 枚举与权限组合

```csharp
int flags = (1 << 0) | (1 << 2);
Console.WriteLine(Convert.ToString(flags, 2).PadLeft(4, '0'));  // 0101
Console.WriteLine((flags & (1 << 2)) != 0);   // True

Console.WriteLine(10 << 1);    // 20
Console.WriteLine(-8 >> 2);    // -2
Console.WriteLine(-8 >>> 2);   // 1073741822
```

#### 6. 空值运算符

- `??` 提供默认值，`??=` 为空时赋值
- `?.` 空条件访问，`?[]` 空条件索引；左侧为空时整个表达式返回 `null`
- `!` 只消除编译警告，不做运行时检查

```csharp
string? name = null;
Console.WriteLine(name ?? "游客");        // 游客

name ??= "Tom";
Console.WriteLine(name?.Length ?? 0);     // 3
Console.WriteLine(name?.ToUpper());       // TOM

string[]? tags = null;
Console.WriteLine(tags?[0] ?? "无标签");  // 无标签
```

> **性能提示**：`?.`、`??` 由编译器生成分支，几乎没有额外开销。

#### 7. 三元运算符

- 语法 `条件 ? 值1 : 值2`，条件必须是 `bool`，右结合
- 嵌套超过两层就改用 `if` 或 `switch` 表达式
- C# 9 起支持目标类型推断

```csharp
int score = 78;
string level = score >= 90 ? "优秀" : score >= 60 ? "及格" : "不及格";
Console.WriteLine(level);

int a = 12, b = 20;
Console.WriteLine(a > b ? a : b);    // 20

object value = score > 60 ? 1 : "低分";
Console.WriteLine(value);
```

#### 8. is、as 与模式匹配

- `is` 判断类型或模式，返回 `bool`，不抛异常
- `is 类型 变量` 匹配成功时顺带赋值
- `as` 失败返回 `null`，只适用于引用类型和可空类型
- 属性模式 `{ Age: >= 18 }`、逻辑模式 `not` / `and` / `or`

```csharp
object obj = "Hello, C#";
if (obj is string text)
{
    Console.WriteLine(text.Length);       // 8
}

string? maybeText = obj as string;
Console.WriteLine(maybeText?.ToUpper());  // HELLO, C#

var person = new Person("Tom", 20);
if (person is { Age: >= 18 } adult)
{
    Console.WriteLine($"{adult.Name} 已成年");
}

public sealed record Person(string Name, int Age);
```

#### 9. sizeof、typeof、nameof

- `sizeof(T)` 取基元类型字节数，编译期常量
- `typeof(T)` 取 `System.Type` 对象，用于反射
- `nameof(x)` 取标识符名称，重构安全
- 溢出检查用 `checked` / `unchecked`，默认不检查

```csharp
Console.WriteLine(sizeof(int));         // 4
Console.WriteLine(sizeof(decimal));     // 16
Console.WriteLine(typeof(List<int>));   // System.Collections.Generic.List`1[System.Int32]
Console.WriteLine(nameof(Person.Age));  // Age

public sealed record Person(string Name, int Age);
```

#### 10. 运算符重载

- 用 `operator` 定义静态方法，如 `operator +`
- 不能重载 `=`、`&&`、`||`、`?:`、`??`
- `==` 与 `!=` 必须成对重载，并重写 `Equals` / `GetHashCode`
- `record` 自动生成值相等；`implicit` / `explicit` 定义转换

```csharp
var p1 = new Vector2(1, 2);
Console.WriteLine(p1 + new Vector2(3, 4));   // (4, 6)
Console.WriteLine(p1 * 2);                   // (2, 4)
Console.WriteLine(p1 == new Vector2(1, 2));  // True

public readonly record struct Vector2(double X, double Y)
{
    public static Vector2 operator +(Vector2 a, Vector2 b) => new(a.X + b.X, a.Y + b.Y);
    public static Vector2 operator *(Vector2 v, double k) => new(v.X * k, v.Y * k);
    public override string ToString() => $"({X}, {Y})";
}
```

#### 11. 运算符优先级

| 优先级 | 类别 | 运算符 | 结合性 |
|--------|------|--------|--------|
| 1（高） | 基本 | `x.y`、`f(x)`、`a[i]`、`x++`、`new`、`typeof`、`nameof` | 左 |
| 2 | 一元 | `+x`、`-x`、`!x`、`~x`、`++x`、`--x`、`(T)x`、`await` | 右 |
| 3 | 乘除 | `*`、`/`、`%` | 左 |
| 4 | 加减 | `+`、`-` | 左 |
| 5 | 移位 | `<<`、`>>`、`>>>` | 左 |
| 6 | 关系与类型测试 | `<`、`>`、`<=`、`>=`、`is`、`as` | 左 |
| 7 | 相等 | `==`、`!=` | 左 |
| 8 | 逻辑与 | `&` | 左 |
| 9 | 逻辑异或 | `^` | 左 |
| 10 | 逻辑或 | `\|` | 左 |
| 11 | 条件与 | `&&` | 左 |
| 12 | 条件或 | `\|\|` | 左 |
| 13 | 空合并 | `??` | 右 |
| 14 | 条件 | `?:` | 右 |
| 15（低） | 赋值与 Lambda | `=`、`+=`、`??=`、`=>` | 右 |

> **注意**：优先级只决定“怎么结合”，不决定求值顺序；操作数仍从左到右求值。记不清就加括号。

#### 12. 小结

| 主题 | 关键结论 |
|------|----------|
| 算术与赋值 | 整数除法截断；复合赋值隐含窄化转换 |
| 比较与逻辑 | 字符串比内容，浮点比误差，`&&` 短路 |
| 位与类型测试 | 移位会取模；`is` 安全，`as` 失败返回 null |
| 优先级 | 不确定就加括号 |
