# 面向对象编程

#### 1. 类与对象

##### 1.1 类、对象与字段

`类`是 `引用类型` 的模板，`对象` 是按模板在堆上创建的实例。类里放 **数据**（字段、属性）与 **行为**（方法、构造函数、索引器、运算符）。

##### 1.2 字段 vs 属性

- **字段**：直接暴露存储，无法校验，公开字段是坏味道
- **属性**：本质是 `get` / `set` 方法，可校验、可只读、可计算（字段 `_camelCase`，属性 `PascalCase`）

```csharp
public class Product
{
    public decimal _price;                          // 字段：谁都能改，无法校验
    public string Name { get; private set; } = "";  // 属性：外部只读，内部可写

    public void Rename(string name) => Name =
        string.IsNullOrWhiteSpace(name) ? throw new ArgumentException("名称不能为空") : name;
}

var p = new Product();
p.Rename("键盘");
p._price = 199m;
Console.WriteLine($"{p.Name} {p._price}");
```

##### 1.3 自动属性与 init

```csharp
public class Account
{
    public string Id { get; set; } = Guid.NewGuid().ToString("N")[..8];  // 自动属性
    public decimal Balance { get; private set; }                         // 外部只读
    public string Owner { get; init; } = "匿名";                         // 仅初始化时可写
    public string Display => $"{Owner}({Id})";                           // 表达式体属性

    public void Deposit(decimal amount) => Balance += amount;
}

var acc = new Account { Owner = "张三" };
acc.Deposit(100m);
Console.WriteLine(acc.Display);
// acc.Owner = "李四";     // 编译错误：init 只能在对象初始化时赋值
```

#### 2. 构造函数

```csharp
public class Order
{
    public string No { get; }
    public decimal Amount { get; }

    public Order() : this("UNKNOWN", 0m) { }      // this(...) 复用另一个构造函数

    public Order(string no, decimal amount) => (No, Amount) = (no, amount);
}

var o1 = new Order();
var o2 = new Order("A001", 99m);
Console.WriteLine($"{o1.No} {o2.No} {o2.Amount}");
```

- 实例构造函数每次 `new` 都执行；`static` 构造函数在类型第一次被使用时执行一次
- 父类构造先于子类构造，`this(...)` / `base(...)` 必须写在第一行

> **注意**：一旦手写了构造函数，编译器就不再生成无参构造。想同时支持 `new Order()` 与 `new Order("A001", 1m)`，必须自己补一个（或用 `this(...)` 链过去）。

#### 3. 封装与访问修饰符

| 修饰符 | 可见范围 |
|--------|----------|
| `public` | 任何代码 |
| `internal` | 同一程序集（类型的默认值） |
| `protected` | 本类及派生类 |
| `private` | 仅本类（成员的默认值） |
| `protected internal` | 同程序集 **或** 派生类 |
| `private protected` | 同程序集 **且** 派生类 |

> **注意**：C# 的默认访问级别最严格——类默认 `internal`，成员默认 `private`。类只有 `public` / `internal` 两种顶层修饰，不能写 `private class`。

#### 4. 继承

##### 4.1 派生与 base

```csharp
public class Animal
{
    public string Name { get; }
    public Animal(string name) => Name = name;
    public virtual string Speak() => "...";
}

public class Dog : Animal
{
    public Dog(string name) : base(name) { }                    // base 调用父类构造
    public override string Speak() => "汪汪" + base.Speak();     // base 调父类实现
}

Console.WriteLine(new Dog("旺财").Speak());   // 多态：按实际类型调用
```

- C# 只支持 `单继承`（一个父类），但可实现 `多个接口`
- 所有类最终派生自 `object`，天然拥有 `ToString()` / `Equals()` / `GetHashCode()`
- 构造函数不被继承，但子类构造必须调用父类构造

##### 4.2 virtual / override / new

```csharp
public class Base
{
    public virtual string Who() => "Base.Who";
    public string Kind() => "Base.Kind";
}

public class Derived : Base
{
    public override string Who() => "Derived.Who";   // 重写：多态生效
    public new string Kind() => "Derived.Kind";      // 隐藏：多态失效
}

Base b = new Derived();
Console.WriteLine(b.Who());                // Derived.Who，按运行时类型
Console.WriteLine(b.Kind());               // Base.Kind，按编译时类型
```

`virtual` 允许重写，`override` 后按 `运行时类型` 调用（多态），`new` 只是隐藏同名成员、按 `编译时类型` 调用。

#### 5. abstract 与 sealed

```csharp
public abstract class Shape
{
    public abstract double Area();                       // 只有签名，没有实现
    public override string ToString() => $"{GetType().Name}: {Area():F2}";
}

public sealed class Circle : Shape                       // sealed：不能再被继承
{
    private readonly double _r;
    public Circle(double r) => _r = r;
    public override double Area() => Math.PI * _r * _r;
}

Console.WriteLine(new Circle(2));    // Circle: 12.57
// new Shape();                    // 编译错误：抽象类不能实例化
// public class Sub : Circle { }   // 编译错误：sealed 不能被继承
```

- `abstract` 类不能实例化，但可以有构造函数、字段和普通方法供子类复用；`sealed` 修饰类禁止继承，修饰 `override` 方法禁止再重写

#### 6. 接口

```csharp
public interface ILogger
{
    void Log(string message);
    void LogError(string message) => Log($"[ERROR] {message}");   // 默认实现（C# 8+）
}

public interface INamed { string Name { get; } }

public class ConsoleLogger : ILogger, INamed       // 一个类可实现多个接口
{
    public string Name => "Console";
    void ILogger.Log(string message)                // 显式实现：只能经接口调用
        => Console.WriteLine($"{Name}: {message}");
}

ILogger logger = new ConsoleLogger();
logger.Log("启动");
logger.LogError("磁盘已满");                        // 走接口默认实现
Console.WriteLine(((INamed)logger).Name);           // Console
```

- 接口成员默认 `public abstract`，不能有字段和实例构造函数，但可以有静态方法与默认实现
- **显式实现** `void ILogger.Log(...)` 避免与类上同名成员冲突，只能通过接口变量调用

#### 7. static 成员

```csharp
public class IdGenerator
{
    private static int _seed;                     // 静态字段：全类型共享一份
    static IdGenerator() => _seed = 1000;         // 类型初始化时执行一次

    public static string Prefix { get; } = "ID-";
    public static int Next() => ++_seed;
}

public static class NumberUtil { public static bool IsEven(int n) => n % 2 == 0; }

Console.WriteLine($"{IdGenerator.Prefix}{IdGenerator.Next()}");   // ID-1001
```

> **注意**：静态方法里没有 `this`，不能访问实例成员。静态字段在进程内只有一份，别用它保存"当前用户"这类请求级状态——并发下会互相覆盖。

#### 8. record

```csharp
public record Point(int X, int Y);              // 位置记录：自动生成构造、属性、解构

public record Person
{
    public required string Name { get; init; }  // required：创建时必须赋值
    public int Age { get; init; } = 18;
}

var a = new Point(1, 2);
var b = new Point(1, 2);
Console.WriteLine(a == b);                      // True，按值比较
Console.WriteLine(a with { Y = 99 });           // Point { X = 1, Y = 99 }
Console.WriteLine(new Person { Name = "张三" }.Age);   // 18
```

| 对比 | `class` | `record` | `record struct` |
|------|---------|----------|-----------------|
| 类型 | 引用 | 引用 | 值 |
| 相等 | 引用相等 | **值相等** | 值相等 |
| `with` | 不支持 | 支持 | 支持 |
| 适用 | 有身份、会变化的对象 | DTO、消息、领域值 | 小的值对象 |

#### 9. struct vs class

```csharp
public struct Vector2
{
    public double X, Y;
    public Vector2(double x, double y) { X = x; Y = y; }
    public readonly double Length => Math.Sqrt(X * X + Y * Y);
}

public class Vector2Class { public double X, Y; }

var v1 = new Vector2(3, 4);
var v2 = v1;                    // 值类型：复制整个结构
v2.X = 100;
Console.WriteLine($"{v1.Length} {v2.X}");        // 5 100

var c1 = new Vector2Class { X = 3, Y = 4 };
var c2 = c1;                    // 引用类型：共享同一对象
c2.X = 100;
Console.WriteLine($"{c1.X} {c2.X}");             // 100 100
```

| 对比 | `struct` | `class` |
|------|----------|---------|
| 类型 / 存储 | 值类型，栈或内联 | 引用类型，堆 |
| 赋值 | 复制整个值 | 复制引用 |
| 继承 | 不能继承类、也不能被继承 | 支持继承 |
| 适用 | 小、短命、不可变（`Guid`） | 有身份、需继承、体积大 |

> **性能提示**：`struct` 超过 16~24 字节后复制成本会超过堆分配收益；尽量写成 `readonly struct` 避免防御性复制。

#### 10. 索引器与运算符重载

```csharp
public class Matrix
{
    private readonly int[,] _data = new int[2, 2];

    public int this[int r, int c]                     // 索引器：obj[1, 0]
    {
        get => _data[r, c];
        set => _data[r, c] = value;
    }
    public static Matrix operator +(Matrix a, Matrix b) => new()
    {
        [0, 0] = a[0, 0] + b[0, 0],
        [1, 1] = a[1, 1] + b[1, 1],
    };
}

var sum = new Matrix { [0, 0] = 1 } + new Matrix { [0, 0] = 3 };
Console.WriteLine(sum[0, 0]);      // 4
```

- **索引器**：`this[参数列表]`，参数就是方括号内容，可重载、可多参数
- 重载 `>` 必须同时重载 `<`；重载 `==` 必须同时重载 `!=` 并重写 `Equals` / `GetHashCode`

#### 11. partial 分部类

```csharp
public partial class OrderService
{
    public void Create() => Console.WriteLine("创建订单");
}

public partial class OrderService          // 另一部分：编译时合并成一个类
{
    public void Cancel() => Console.WriteLine("取消订单");
}

var svc = new OrderService();
svc.Create();
```

分部类把一个大类拆到多个文件：设计器生成的部分（WPF / WinForms）与人写的部分分开，避免手写代码被覆盖。所有部分的 `abstract` / `sealed` / 基类声明必须一致。

#### 12. 小结

| 知识点 | 关键结论 |
|--------|----------|
| 属性 | 优先属性而非公开字段；`init` 不可变，`private set` 受控可变 |
| 构造 | `this(...)` / `base(...)` 在第一行；静态构造只执行一次 |
| 继承 | 单继承 + 多接口；`virtual` / `override` 多态，`new` 是隐藏 |
| 抽象 | `abstract` 不能实例化；`sealed` 禁止继承或再重写 |
| 值类型 | `record` 值相等 + `with`；`struct` 只用于小而不变的值 |
