MOKIDOWN / PLUGIN SDK 1.3.0

插件开发文档

插件运行在隔离环境里，通过 SDK 读取文档、注入界面、访问授权目录。本页是 SDK 1.3.0 的完整参考，apiVersion 保持为 1，旧插件无需修改。

从零创建插件→API 参考→
01能力驱动

先查询 capabilities，再调用接口；宿主降级时插件按需跳过。

02无全局访问

不暴露 DOM、store 或绝对路径；文件与网络都经宿主白名单。

03声明式界面

界面由宿主渲染，插件只提交数据：状态栏、任务、徽标、版本列表、对比。

01 / SETUP

安装与要求

需要 Node.js 22.13 或更高版本。开发工具随 MokiDown 源码提供，插件项目通过本地 SDK 获得类型提示。

环境版本说明
Node.js≥ 22.13运行打包与开发服务
MokiDown≥ 0.1.5设置 → 语言服务 → 插件开发
SDK1.3.0随源码提供，无需单独安装
02 / QUICKSTART

第一个插件

脚手架会生成清单、SDK 类型、开发服务与一个可运行入口。修改源码后开发服务重新构建，编辑器校验新包并重载运行环境，通常约 2 秒生效。

Terminal
npm ci
npm run plugin:create -- ./my-plugins/reading example.reading
npm run plugin:dev -- ./my-plugins/reading
  1. 1
    连接开发服务

    打开「设置 → 语言服务 → 插件开发」，填入终端打印的 http://127.0.0.1:3141/package，点击连接。

  2. 2
    保存即生效

    编辑 src/index.mjs 或样式文件，开发服务重新构建，编辑器替换运行环境。

  3. 3
    打包交付

    执行打包命令，取得带版本号与摘要的单文件包，可导入或发布到 Release。

Terminal
npm run plugin:pack -- ./my-plugins/reading
# or inside the generated project: npm run dev / npm run build
开发会话只连本机

仅支持 127.0.0.1、localhost 与 IPv6 回环的 HTTP 地址。会话不自动恢复；增加权限后需断开重连；构建失败会保留上一次可用包。

03 / PROJECT

项目结构

Project
reading/
├─ manifest.json       # id / name / version / permissions / configuration
├─ package.json        # dev / build scripts and local SDK types
├─ .moki.mjs           # tool entry generated by the scaffold
└─ src/
   ├─ index.mjs        # definePlugin entry
   └─ reading.css      # removable Markdown styles

插件只导入 @mokidown/sdk，不引用编辑器内部组件或 store。移动插件目录后用 MOKIDOWN_TOOLS 指向源码 scripts 目录即可继续开发。

04 / MANIFEST

清单与权限

只声明实际使用的权限。fileExtensions 限定工作区读写的文件类型；纯样式插件可以不声明文件权限。

manifest.json
{
  "format": "mokidown-extension-v2",
  "id": "example.reading",
  "name": "阅读助手",
  "version": "1.0.0",
  "entry": "src/index.mjs",
  "permissions": ["editor.read", "ui.statusBar", "styles.markdown"],
  "configuration": {
    "fields": [
      {"key": "fontSize", "label": "正文字号", "type": "number", "default": 16, "min": 12, "max": 28}
    ]
  }
}
权限开放的能力
editor.read文档列表、正文、选区、差异与版本
editor.writeapplyEdits / setSelection / focus / reload
workspace.read / workspace.write授权目录的列举、读取、写入、删除
storage插件独立持久化（get / set / keys / delete）
network访问配置的服务地址（凭据由宿主附加）
commands注册与注销命令
ui.statusBar / ui.fileIcons / ui.notifications状态、任务、图标、徽标、通知
styles.markdown注入可撤销的 Markdown 样式
05 / CONFIGURATION

配置声明

设置页的表单完全由清单里的 configuration 生成，编辑器不内置任何插件的字段。保存配置会重启插件并保留启用状态；访问密钥由宿主保存，不会返回给插件。

字段类型值渲染
textstring单行输入
numbernumber数字输入（min/max）
booleanboolean开关
selectstring下拉（options）
urlstring服务地址输入
secretcredential密码框，固定 key 为 credential
directoryworkspace目录选择，固定 key 为 workspace

连接测试也由插件声明：给出请求路径、需要校验的响应字段和成功/失败文案，编辑器只负责执行与展示。

manifest.json → configuration.test
"test": {
  "path": "/capabilities",
  "check": ["service", "plugins"],
  "success": "连接成功",
  "failure": "请检查服务地址、反向代理或隧道是否在线。"
}
06 / EDITOR

文档与编辑

文档快照包含未保存正文、语言与 SHA-256 校验和。编辑与设置选区都需要 expectedChecksum，避免异步返回覆盖用户后续输入。偏移使用 UTF-16，与 JavaScript 字符串一致；多个编辑范围不得重叠。

src/index.mjs
import { definePlugin } from '@mokidown/sdk';

definePlugin(async (sdk) => {
  await sdk.commands.register('reading.quote', '添加引用', async () => {
    const selection = await sdk.editor.getSelection();
    if (!selection?.text) return;
    await sdk.editor.applyEdits(selection.documentId, selection.checksum, [{
      from: selection.from, to: selection.to,
      text: '> ' + selection.text,
    }]);
  });
});
源码与富文本

选区读取、选区定位与文本编辑当前仅支持源码编辑器；富文本模式下返回 SOURCE_EDITOR_REQUIRED。编辑走原生撤销栈，应用修改不会自动保存到磁盘。

onDidChangeContent 在输入暂停约 120ms 后发送 { documentIds }，不携带整篇正文；需要时用 getDocument(id) 读取。onDidChangeDocuments 负责标签打开、切换与关闭；onDidSave 负责保存事件。

07 / UI

界面贡献

插件在隐藏的隔离环境执行，不创建独立页面。通过 SDK 注册编辑器贡献：状态栏可绑定文档，任务显示进度，文件图标支持路径或扩展名，版本列表展示插件提供的历史源。

Status, task and versions
await sdk.statusBar.set('reading.state', {
  documentId: doc.id, text: '检查完成', tone: 'success',
  command: 'reading.review',
});

await sdk.tasks.set('reading.scan', {
  title: '检查文档', status: '2 / 5', progress: 0.4,
  command: 'reading.review',
});

await sdk.versions.set({
  path: doc.relativePath, title: '云端历史',
  items: [{ id: 'v2', rev: 2, label: 'rev 2', meta: '今天 10:24' }],
});
接口说明
statusBar.set / remove底栏状态，可绑定 documentId 与命令
tasks.set / remove任务列表条目与进度
fileIcons.set / remove按扩展名或路径替换文件图标
fileBadges.set / remove文件状态徽标（SVG）
versions.set / remove侧栏版本列表，选中与刷新走 onDidSelect / onDidRequestRefresh
editor.showDiff / showVersions打开对比视图或版本面板
notifications.show编辑器风格的通知
08 / STYLES

样式注入

样式注入限定在 Markdown 内容区域，禁用外部资源与脚本；卸载或禁用插件时样式自动撤销。注入前先做作用域收敛，避免影响编辑器自身的界面。

src/index.mjs
const css = `
.markdown-body h1 { letter-spacing: 0.01em; }
.markdown-body blockquote { border-left: 3px solid var(--accent); }
`;
await sdk.styles.setMarkdown('reading.typography', css);
// sdk.styles.remove('reading.typography') on disable
09 / API REFERENCE

SDK API

SDK 1.3.0 保持 apiVersion: 1。先查询能力，再调用新接口；旧宿主会自动降级。

Capability discovery
const context = await sdk.context();
if (await sdk.capabilities.has('editor.selection')) {
  const selection = await sdk.editor.getSelection();
  // { documentId, from, to, text, checksum }
}

10 / LIFECYCLE

事件与生命周期

definePlugin 的回调返回后插件进入运行状态；宿主通过 AbortSignal 与 onDispose 释放资源。禁用、卸载或重载时，命令、样式、状态项与徽标全部撤销。

事件触发时机
documentsChanged标签打开、切换、关闭
didSave文档保存（含另存为）
didChangeContent输入停顿约 120ms
themeChanged深浅主题切换
versionSelected / versionRefresh版本列表选中 / 刷新
Dispose
definePlugin(async (sdk) => {
  const timer = setInterval(refresh, 30_000);
  sdk.onDispose(() => clearInterval(timer));

  if (sdk.signal.aborted) return;
  await sdk.editor.onDidSave(() => refresh());
});
11 / PACKAGING

打包与版本

打包生成单文件 .mokiplugin.json，包含规范化 JSON 摘要；清单版本、Release tag 与目录条目必须一致。

Terminal
npm run plugin:pack -- ./my-plugins/reading
# → releases/plugins/reading-1.0.0-<digest>.mokiplugin.json
检查项要求
manifest.version与产物文件名一致
Release tagv + 同一版本号
目录 sha256使用打包输出的 canonical 值，不是文件字节哈希
12 / DISTRIBUTION

分发与更新

发布到 GitHub Release 后，把版本、下载地址与摘要写入服务插件目录；编辑器检测到更高版本后提示更新，下载时按摘要校验。也可以直接用「导入插件包」安装本地文件。

service-plugins.json
[{
  "id": "example.reading",
  "name": "阅读助手",
  "version": "1.0.0",
  "url": "https://github.com/…/reading-1.0.0-<digest>.mokiplugin.json",
  "sha256": "<canonical digest>"
}]
13 / TROUBLESHOOTING

排错

现象原因与处理
PLUGIN_CHECKSUM_MISMATCH目录摘要与规范化 JSON 不符；改用打包输出值。
PLUGIN_INVALID_PACKAGE包不是有效 JSON 或清单字段缺失；检查 format / id / version / entry。
SOURCE_EDITOR_REQUIRED富文本模式下调用了选区或编辑接口；切回源码模式。
权限被拒清单未声明对应权限；增加权限后断开并重连开发会话。
样式没有生效选择器需限定在 .markdown-body 内，且不能引用外部资源。
